# Warp Drive Effect Prototypes

Five functional HTML5/JS/CSS prototypes for different warp drive visual effects. Each is a standalone HTML file that can be opened directly in a browser.

## Files

### 1. `star-streak-tunnel.html`
**Star Streak Tunnel Effect**
- Creates a 3D tunnel effect with stars streaking toward the viewer
- Stars accelerate when warp is active
- Horizontal scanlines appear during warp
- Colors shift to blue/purple during activation
- Smooth, continuous animation

**Controls:**
- **Start Warp** / **Stop Warp**: Toggle warp effect on/off
- **Reset**: Reset all stars to starting positions

---

### 2. `space-distortion-wave.html`
**Space Distortion Wave Effect**
- Waves of gravitational lensing distortion roll across the screen
- Background starfield warps and bends during warp
- Color overlay shifts to blue/violet
- Scanlines bend with the distortion
- Creates a sense of space-time warping

**Controls:**
- **Start Warp** / **Stop Warp**: Toggle distortion waves
- **Reset**: Return to normal view

---

### 3. `hyperspace-jump.html`
**Hyperspace Jump Sequence**
- Multi-phase sequence: Normal → Fade Out → Flash → Warp → Fade In
- Stars twinkle normally, then fade to black
- Intense white/blue flash during jump
- Star streaks during warp phase
- Returns to normal starfield
- One-time sequence (must click to initiate)

**Controls:**
- **Initiate Jump**: Start the complete hyperspace jump sequence
- Button disables during sequence (prevents interruption)

---

### 4. `static-to-warp.html`
**Static to Warp Transition**
- Begins with TV static/glitch pattern
- Static coalesces into streaks moving toward center
- Transitions into full star streak tunnel effect
- Progressive transformation effect
- Combines retro CRT aesthetic with warp effect

**Controls:**
- **Start Transition**: Begin the static-to-warp sequence
- Auto-advances through phases
- **Reset**: Return to static phase

---

### 5. `cosmic-ribbon.html`
**Cosmic Ribbon Effect**
- Colorful energy ribbons flow from screen edges toward center
- Multiple ribbons with different colors (magenta, cyan, orange, purple, etc.)
- Animated particles/stars travel along ribbons
- Glowing, pulsing ribbon effects
- Overall blue color overlay during warp
- High-energy, dynamic visual

**Controls:**
- **Start Warp** / **Stop Warp**: Toggle ribbon effects
- **Reset**: Regenerate ribbon paths

---

## How to Use

1. Open any HTML file directly in a web browser
2. Use the control buttons to interact with each effect
3. Each prototype is fully self-contained (no dependencies)
4. Resize the browser window to see how effects adapt

## Technical Details

- **Pure HTML5 Canvas**: All effects use HTML5 Canvas API
- **No Dependencies**: No external libraries required
- **RequestAnimationFrame**: Smooth 60fps animations
- **Responsive**: Adapts to window size
- **Performance Optimized**: Efficient rendering for smooth performance

## Recommended Usage in Game

Each effect could be adapted for:
- **Background overlay** during warp sequences
- **Transition effect** between scenes or segments
- **Menu background** animation
- **Victory/achievement** visual
- **Loading screen** enhancement

Choose the effect that best matches your game's aesthetic and performance requirements!
