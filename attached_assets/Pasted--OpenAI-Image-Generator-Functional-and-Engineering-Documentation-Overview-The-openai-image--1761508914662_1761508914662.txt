# OpenAI Image Generator - Functional and Engineering Documentation

## Overview

The `openai_image.py` script is a sophisticated command-line interface (CLI) tool for generating images using OpenAI's image generation models. It features dynamic CLI parameter generation through runtime type introspection, making it automatically compatible with new OpenAI API parameters without code changes.

## Functional Specification

### Purpose
Generate images from text prompts using OpenAI's image generation models with a user-friendly CLI interface that automatically adapts to API changes.

### Core Features

1. **Dynamic CLI Generation**: Automatically introspects OpenAI's `Images.generate` method to create CLI parameters
2. **Flexible Model Support**: Supports any OpenAI image model with intelligent defaults
3. **Automatic Parameter Discovery**: Extracts valid choices from `Literal` type annotations
4. **Performance Monitoring**: Measures and reports API call duration
5. **Smart Output Handling**: Generates unique filenames and handles base64 decoding
6. **Comprehensive Logging**: Outputs detailed JSON metadata to stderr

### Command Line Interface

#### Required Arguments
- `PROMPT`: Text description of the image to generate

#### Optional Arguments
- `OUTFILE`: Output file path (defaults to `/tmp/image-<6-hex>.png`)

#### Options
- `-m, --model`: Image generation model (default: `gpt-image-1-mini`)
- `--background`: Background setting (auto-discovered from API)
- `--moderation`: Moderation setting (auto-discovered from API)
- `--output-format`: Output format (auto-discovered from API)
- `--quality`: Image quality setting (auto-discovered from API)
- `--size`: Image size (auto-discovered from API)

### Usage Examples

```bash
# Basic usage
python openai_image.py "a futuristic cityscape"

# Specify model and output file
python openai_image.py "a cat wearing a space helmet" --model dall-e-3 --output my_image.png

# Use discovered parameters
python openai_image.py "abstract art" --quality hd --size 1024x1024
```

## Engineering Architecture

### Design Patterns

1. **Dynamic CLI Construction**: Uses runtime introspection to build CLI parameters
2. **Type-Safe Parameter Extraction**: Leverages Python's typing system for parameter discovery
3. **Graceful Fallback Handling**: Handles missing or incompatible type annotations
4. **Separation of Concerns**: Clear separation between CLI construction and execution logic

### Core Components

#### 1. Type Introspection System

**Purpose**: Extracts valid parameter choices from Python type annotations, specifically `Literal` types.

**Key Functions**:
- `_is_literal(ann)`: Detects `Literal` type annotations
- `_is_union(ann)`: Identifies union types
- `_is_optional(ann)`: Detects optional types (Union with None)
- `_skip_ann(ann)`: Filters out sentinel values like `NotGiven`
- `literal_choices(annotation)`: Main function that recursively extracts all valid choices

**Key Features**:
- Handles nested union types and optional types
- Filters out sentinel values like `NotGiven`
- Recursively walks complex type hierarchies
- Deduplicates choices using a set

#### 2. Dynamic CLI Builder

**Purpose**: Constructs a Click CLI command dynamically based on OpenAI API type hints.

**Process**:
1. Uses `get_type_hints` with `include_extras=True` for full type information
2. Creates positional arguments for prompt and optional output file
3. Dynamically generates options for known API parameters
4. Provides intelligent help text with discovered choices

**Key Features**:
- Automatic parameter discovery from API types
- Intelligent help text generation
- Support for both required and optional parameters
- Case-sensitive choice validation

#### 3. Execution Engine

**Purpose**: Handles the actual image generation, timing, and output processing.

**Process Flow**:
1. Validates API key presence
2. Generates unique output filenames using `secrets.token_hex`
3. Prepares parameters for API call
4. Measures API call performance with `time.perf_counter`
5. Handles response parsing (both Pydantic and JSON)
6. Saves base64-decoded image data to file
7. Provides comprehensive logging to stderr

**Key Features**:
- High-precision timing measurement
- Flexible response handling
- Secure filename generation
- Comprehensive error reporting

### Performance Characteristics

#### Timing Precision

#### Memory Efficiency
