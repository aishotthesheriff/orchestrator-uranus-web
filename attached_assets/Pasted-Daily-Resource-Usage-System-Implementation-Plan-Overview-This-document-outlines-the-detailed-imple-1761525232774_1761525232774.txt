Daily Resource Usage System - Implementation Plan
Overview
This document outlines the detailed implementation plan for adding daily resource consumption mechanics to the Uranus Dungeon Guide game. The system will automatically consume resources each day, creating strategic depth and time pressure while maintaining compatibility with existing game mechanics.
Current System Analysis
Existing Stat System
Core Stats: hull, oxygen, fuel, food, morale, weirdness
Stat Ranges: 0-100 (except weirdness: 0-5)
Change Mechanism: Delta strings (e.g., "fuel-5,morale-1")
Application: applyDelta() function in gameEngine.ts
Day Progression: Every 2 turns (turnNumber % 2 === 0)
Current Integration Points
Event System: Events modify stats via passEffect/failEffect
Action System: Player actions have base consequences
Item System: Equipped items provide scene-based stat effects
Turn System: Stats are displayed in turn delta arrays

Configuration Options
Easy Mode (Lower Consumption)
Hard Mode (Higher Consumption)
Migration Strategy
Backward Compatibility: Existing games will have daily consumption applied from their current day forward
Gradual Rollout: Feature can be toggled via game settings
Data Migration: No database changes required, only schema additions
Fallback Handling: Games without daily consumption data will use default rates
Success Metrics
Engagement: Increased session length due to resource management
Strategy: More diverse action choices based on resource needs
Difficulty: Appropriate challenge level maintained
Performance: No significant impact on game performance
User Satisfaction: Positive feedback on strategic depth
This implementation plan provides a comprehensive roadmap for adding daily resource usage while maintaining the existing game's charm and functionality. The modular approach allows for incremental implementation and easy adjustment of consumption rates based on playtesting feedback.
